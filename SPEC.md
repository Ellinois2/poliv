# Полив — описание продукта

Версия 0.1 · 28 октября 2026 · эталон дизайна: `prototype.dc.html`

## Суть

Android-приложение для учёта полива и подкормки комнатных растений. Показывает, что полить и подкормить сегодня, позволяет отметить это одним тапом или голосом и напоминает по расписанию каждого растения.

## Для кого и где

- Пользователь: один человек, до ~20 растений.
- Сначала приложение только для владелицы (установка APK), потом — публикация в RuStore.
- Платформа: **только Android**. iOS не делаем.
- `applicationId`: **`ru.ellin.poliv`** — не меняется никогда.
- Целевое устройство владелицы: **Huawei Y8P, EMUI 10 (Android 10, API 29)**. Скорее всего без сервисов Google (не проверено: есть ли на телефоне Google Play). Поэтому:
  - никаких зависимостей от Google Play Services (Firebase, FCM, ML Kit от Google, системный SpeechRecognizer Google);
  - уведомления только локальные;
  - распознавание речи офлайн — Vosk с русской моделью.
- `minSdk` 26 (Android 8.0), `targetSdk` — актуальный, который требует RuStore.

## Стек

- Kotlin, Jetpack Compose, Material 3 с собственной темой.
- Room (SQLite) — растения и события; DataStore — настройки.
- AlarmManager для уведомлений в точное время, WorkManager для обслуживающих задач; перепланирование после перезагрузки (`BOOT_COMPLETED`).
- Vosk (офлайн, маленькая русская модель) — этап 4.
- Сборка в GitHub Actions, APK скачивается из артефакта сборки. Релизная подпись — ключом из GitHub Secrets.
- В первой версии нет сервера и аккаунта: все данные только на телефоне.

## Экраны

### Главная

- Заголовок «Мои растения», под ним «N растений». Справа две круглые кнопки: «+» (добавить растение) и «настройки» (иконка ползунков; в настройках же аккаунт).
- Две плитки во всю ширину: «Полив» и «Подкормка». В плитке:
  - иконка (капля / росток), название, шеврон;
  - крупное число (44 sp) и «растения ждут»; если всё сделано — «Всё полито» / «Всё подкормлено»; если на сегодня ничего — «Сегодня ничего»;
  - оранжевая плашка «Просрочено: N», если есть просрочка;
  - полоса прогресса: по сегменту на каждое растение «на сегодня» (сделано — акцент, просрочено — светло-оранжевый, ждёт — серый);
  - **под полосой текста нет**.
- Тап по плитке открывает список.
- Круглая кнопка голоса 56 dp в правом нижнем углу, только иконка микрофона (для скринридера — «Отметить голосом»). На главной понимает и полив, и подкормку.

### Список «Полив» / «Подкормка» (один экран, два режима)

- Шапка: кнопка «‹ Главная» и «+». Метка режима (иконка и «ПОЛИВ» / «ПОДКОРМКА»).
- Заголовок: «N растения ждут полива» / «…подкормки», «На сегодня всё полито» / «…подкормлено», «Сегодня поливать нечего» / «…подкармливать нечего».
- Подстрока: «Готово D из N» / «Отмечайте кнопкой справа или голосом» / «Дальше — Имя, завтра». **Строки про просрочку под заголовком нет.**
- Полоса прогресса, как на плитке.
- Секции:
  - «Полить сегодня» / «Подкормить сегодня» — просроченные первыми;
  - «Скоро» — через 1–3 дня;
  - «Остальные · N» — свёрнута по умолчанию. В подкормке, если там только растения на паузе, она называется «На паузе до марта · N».
- Строка: аватар (фото или заглушка — иконка растения в горшке на пастельном цвете), имя, подстрока; справа кнопка 48 dp — капля (полив) или росток (подкормка). После отметки кнопка залитая с галочкой, повторный тап отменяет отметку.
- Подстроки: «Полито в 14:32» (акцент), «Просрочено на 2 дня · гостиная» (оранжевый), «Гостиная · полив 7 дней назад», «Завтра · гостиная», «Через 3 дня · коридор», «Пауза до марта · спальня», «Не подкармливается». Если место не указано, его часть просто не пишется.
- После отметки строки не переставляются, чтобы список не прыгал.
- Тап по строке открывает карточку растения на вкладке текущего режима.
- Кнопка голоса — та же круглая справа внизу, но работает только в контексте экрана (только полив или только подкормка).
- Сообщение с отменой появляется над кнопкой голоса на 5 секунд: «Полив отмечен: Монстера · Отменить».

### Карточка растения (нижний лист)

- Аватар, имя, место (или «Место не указано»), кнопка закрыть.
- Вкладки «Полив» / «Подкормка».
- Две плитки: «Последний полив» / «Последняя подкормка» (значение и «отмечено голосом / вручную») и «Следующая» (дата и «Через N дней», при просрочке — «Просрочено на N дней» оранжевым; у подкормки на паузе — «1 мар» и «Зимняя пауза»).
- Кнопка «Отметить полив» / «Отменить полив» (и то же для подкормки).
- Расписание полива:
  - «Поливать раз в» [−] N дней [+], диапазон 1–365;
  - под ним теги-пресеты: **7 дней · 14 дней · 1 мес. (30) · 6 мес. (180)**, тап сразу ставит число дней;
  - «Отсчитывать срок»: «От последнего полива» / «По календарю»;
  - «Зимой поливать реже» (ноябрь–февраль, интервал ×1,5).
- Расписание подкормки:
  - «Подкармливать» вкл/выкл;
  - «Подкармливать раз в» [−] N недель [+], диапазон 1–12;
  - «Сезон»: «Март — сентябрь» / «Круглый год».
- Напоминания: «Напоминать о поливе» / «…о подкормке» вкл/выкл; «Как присылать»: «В утренней сводке» / «Отдельно» (время 08:00, 12:00, 19:00, 21:00). Если уведомления выключены в настройках приложения, показать предупреждение.
- История поливов / подкормок: дата и способ отметки.
- **Добавить (в прототипе нет):** редактирование имени, места, фото и удаление растения.

### Добавление растения (полный экран)

Порядок блоков:

1. **Фото — необязательно.** Круг-заглушка (иконка растения на пастельном цвете) со значком камеры; камера или галерея.
2. **Название — обязательно.** Проверка похожих: если первое слово совпадает с уже существующим растением — предупреждение «Уже есть: Фикус Бенджамина, Фикус лировидный. Голосом называйте их полностью — или дайте этому растению другое имя.» При точном совпадении — «Растение с таким названием уже есть…».
3. **Полив.** «Поливать раз в» (по умолчанию 7 дней) с теми же тегами-пресетами. «Когда поливали последний раз»: «Сегодня» / «Вчера» / «Неделю назад» / «Не помню» («Не помню» = полить сегодня). Подсказка с датой следующего полива.
4. **Подкормка.** Вкл/выкл, раз в N недель (по умолчанию 2), сезон (по умолчанию «Март — сентябрь»). Подсказка: «Сейчас не сезон — первое напоминание придёт в марте» или «Первое напоминание — <дата>».
5. **Напоминания.** Вкл/выкл и подсказка про утреннюю сводку.
6. **«Где стоит» — необязательно, в самом низу.** Чипы уже существующих мест и «+ Новое место».

Кнопка внизу экрана «Добавить растение». Без названия она неактивна и пишет «Укажите название». После добавления — возврат на экран, откуда пришли, и сообщение «Добавлено: Имя».

Поля «Как ещё вы его называете» нет — убрано.

### Настройки

- **Аккаунт.** В первой версии блок не показываем (аккаунта и синхронизации пока нет).
- **Уведомления.** Общий переключатель; время утренней сводки 08:00 / 09:00 / 10:00; «Напомнить вечером о пропущенном» (в 20:00, только если что-то осталось неотмеченным); «Тихие часы» 22:00–08:00.
- **Голос.** «Сохранять сразу, если всё понятно» (по умолчанию включено); язык распознавания — русский.
- **Оформление.** Тема.
- **Растения и данные.** «Места» (управление списком мест), «Экспорт истории» (CSV).

### Голосовой ввод (нижний лист)

- Состояние «Слушаю»: пульсирующий микрофон, волна, распознаваемый текст в реальном времени, подсказка с примером, кнопки «Отмена» и «Готово». Остановка по тишине.
- Если всё распознано однозначно и включено «Сохранять сразу» — сохраняем сразу и показываем сообщение с отменой.
- Иначе — «Проверьте, что отметить»:
  - распознанная фраза в кавычках;
  - найденные растения с галочками, подпись вида «Полив · гостиная»;
  - блок неоднозначности: «„Фикус“ — у вас их два. Какой полили?» с вариантами и «Оба»; если одно из растений как раз ждёт этого действия, подписать это в варианте («ждёт подкормки»);
  - «Когда»: «Сейчас» / «Утром» / «Вчера»;
  - кнопки «Заново» и «Отметить N полива / подкормки / действия».
- Разбор фраз — правилами, без ИИ и без сети:
  - «полила / полил / поливала» → полив; «подкормила / подкормил / удобрила» → подкормка;
  - названия с учётом падежей («монстеру» → Монстера): нормализация окончаний и нечёткое сравнение;
  - «вчера», «утром», «всё в <место>»;
  - несколько растений через «и» и запятые; в одной фразе может быть и полив, и подкормка.
- Подсказки: на главной — «Скажите, что полили или подкормили. Например: „полила монстеру, подкормила орхидею“»; в «Поливе» — «…можно добавить „вчера“ или сказать „всё в гостиной“».

## Логика сроков

- Полив: `due = интервал − дней с последнего полива`. `due < 0` — просрочено, `due = 0` — сегодня, `1–3` — скоро, `> 3` — остальные.
- «От последнего полива» (по умолчанию): если полили раньше, следующий срок сдвигается. «По календарю»: напоминание приходит в те же дни, даже если полили раньше.
- «Зимой реже»: с ноября по февраль интервал ×1,5.
- Подкормка: интервал в неделях. Сезон «Март — сентябрь» → с октября по февраль пауза; «Круглый год» — без паузы.
- Отметка — это событие: растение, тип (полив/подкормка), время, способ (голос / вручную / при добавлении). Отмена доступна 5 секунд.
- Утренняя сводка — одно уведомление со всем, что нужно сделать сегодня. Для растений с «Отдельно» — своё уведомление в выбранное время.

## Данные

- `Plant`: id, name, place?, photoUri?, colorTint, waterIntervalDays, waterFrom (LAST | CALENDAR), winterLess, waterRemind, feedOn, feedIntervalWeeks, feedSeason (WARM | ALL), feedRemind, delivery (DIGEST | SEPARATE), separateTime, createdAt.
- `CareEvent`: id, plantId, kind (WATER | FEED), at, source (VOICE | MANUAL | ADD).
- Настройки (DataStore): notificationsOn, digestTime, eveningReminder, quietHoursFrom/To, voiceAutoSave, theme.

## Особенности Huawei / EMUI

- EMUI агрессивно закрывает фоновые приложения. В приложении нужен экран-подсказка: Настройки телефона → Приложения → Запуск приложений → «Полив» → управлять вручную, включить автозапуск, косвенный запуск и работу в фоне.
- На Android 12+ нужно разрешение на точные будильники, на Android 13+ — на уведомления (для других телефонов; на Android 10 их нет).
- Установка APK — разрешить установку из неизвестных источников.

## Этапы

На каждый следующий этап идём только после «зелёного света» владелицы. Каждый этап заканчивается APK, который она ставит на телефон и проверяет.

0. **Основа.** Проект, тема и шрифт, сборка APK в GitHub Actions, ключ подписи (хранит владелица; в репозиторий не кладём, только в Secrets). Результат: заглушка ставится на телефон.
1. **Растения и полив.** Добавление, список «Полив», отметка и отмена, карточка (вкладка «Полив»), редактирование и удаление растения. Без уведомлений.
2. **Подкормка и главная** с плитками.
3. **Уведомления** и подсказка про настройки EMUI.
4. **Голос** (Vosk, офлайн).
5. **Настройки и доводка:** фото, экспорт, пустые состояния, подсказка к кнопке голоса при первом запуске. Итог — версия для себя; 2–4 недели использования и сбор правок.
6. **Публикация в RuStore:** политика конфиденциальности (страница на GitHub Pages), иконка, скриншоты, описание, подписанная сборка.
7. **Монетизация** (позже, по решению владелицы): бесплатная версия и разовая покупка через RuStore.

## Решения и открытые вопросы

Принято:

- Только Android, `ru.ellin.poliv`.
- Место и фото необязательные; у фото есть заглушка.
- Аккаунт живёт в настройках, отдельной кнопки нет.
- Голос на главной понимает оба действия, внутри экранов — только своё.
- Кнопка голоса — круглая, только иконка, в правом нижнем углу.

Открыто:

- Пресет «6 мес.» для полива: риск случайного нажатия — растение пропадёт из напоминаний на полгода. Предложено заменить на «3 дня». Пока оставлено по решению владелицы.
- Не проверено, есть ли на телефоне Google Play.
- Статус для получения выплат (самозанятость или ИП) — решить до этапа 7.
